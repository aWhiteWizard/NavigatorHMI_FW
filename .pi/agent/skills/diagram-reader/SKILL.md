# 审图员（Diagram Reviewer）

主代理（可能是非视觉模型）无法直接看图时，将图纸/照片委派给视觉模型分析。

## 调用方式

**调用前先向用户播报一行**：

> 🔍 调用审图员（kimi-k3）：读取 `<图片路径>`，提取 `<目标信息>`

然后执行：

```bash
pi -p --provider moonshotai-cn --model kimi-k3 "<审图任务简报>"
```

- 必须使用**支持图片的模型**（`/model` 列表中 `图` 列为 `yes` 的）
- 模型 ID 以 `/model` 列表为准
- 子代理可用 `read` 工具直接读图片文件（png/jpg/gif 等）

## 适用与不适用

**适用**：原理图引脚分析、PCB 接线核对、硬件照片诊断、时序图解读
**不适用**：纯文本分析（主代理或文档检索员）、代码审查

## 任务简报模板

1. **图片路径** + 观察目标（"这些是原理图的 4 页，我要找 LCD 触摸 INT/RST 引脚和以太网 PHY 复位引脚"）
2. **具体问题**：要提取什么信息（引脚号、网络名、连接关系）
3. **项目上下文**（板子型号、主控芯片、已知的部分事实）
4. **输出要求**：逐页报告关键电路、引脚连接对照表

## 主代理职责

- 提前想好要问的问题（审图员看图能力强，但不了解项目上下文）
- 收到报告后交叉验证（与文档/代码对照）
- 最终修改 dts/驱动仍由主代理执行
