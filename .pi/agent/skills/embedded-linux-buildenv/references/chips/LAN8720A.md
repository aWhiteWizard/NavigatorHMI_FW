# LAN8720A 以太网 PHY

> 数据手册: `LAN_8720A-CP_datasheet.pdf`, `LAN8720A-CP-TR_中文简介.pdf`

## 基本参数

| 项目 | 值 |
|------|-----|
| 型号 | LAN8720A（SMSC/Microchip） |
| 接口 | RMII |
| ENET1 PHY 复位 | GPIO5_IO07（SNVS_TAMPER7） |
| ENET2 PHY 复位 | GPIO5_IO08（SNVS_TAMPER8） |
| ENET1 MDIO 地址 | 0x0（PHYAD0 拉低） |
| ENET2 MDIO 地址 | 0x1（PHYAD0 拉高） |
| 复位脉宽 | 200ms（`phy-reset-duration = <200>`） |

```dts
    phy-reset-gpios = <&gpio5 7 GPIO_ACTIVE_LOW>;

&fec2 {

    phy-reset-gpios = <&gpio5 8 GPIO_ACTIVE_LOW>;

    mdio {
        #address-cells = <1>;

            compatible = "ethernet-phy-ieee802.3-c22";

    };

```

## 内核配置

```
CONFIG_SMSC_PHY=y
```

## pinctrl（复位引脚）

```dts
/* SNVS 域下 iomuxc_snvs */
pinctrl_enet1_reset: enet1resetgrp {
    fsl,pins = <MX6ULL_PAD_SNVS_TAMPER7__GPIO5_IO07  0x10B0>;
};
pinctrl_enet2_reset: enet2resetgrp {
    fsl,pins = <MX6ULL_PAD_SNVS_TAMPER8__GPIO5_IO08  0x10B0>;
};
```

## 调试踩坑

### 1. NXP EVK 遗留的 SPI 扩展器（74LV595）
NXP EVK dts 里 FEC 的 `phy-reset-gpios` 引用 `&gpio_spi`（一颗 74LV595 移位寄存器）。
**正点原子板子上没有这个芯片**——直接用独立 GPIO（`gpio5_7`/`gpio5_8`）复位。
需要 `/delete-property/ phy-reset-gpios;` 清除继承的 EVK 配置后重新赋值。

### 2. 缺少 `smsc,disable-energy-detect`
无此属性时 LAN8720A 在无网络活动时自动掉电，表现为 `ifconfig up` 成功但 `udhcpc` 拿不到 IP。
必须在 ethphy 节点加 `smsc,disable-energy-detect;`。

### 3. Mini 底板只有 1 个 PHY
Mini V1.7 底板的 ENET1 MAC 信号去 P4 排针（未贴 PHY），板上唯一的 RJ45 接的是 ENET2。
`ifconfig eth1 up` 能拿到 IP，`eth0` 永远起不来。
